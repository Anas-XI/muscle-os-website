Security & Data Encryption Architecture

Effective Date: September 2026 · Compliant with GDPR Article 32 & Modern Cryptographic Standards
🔒 TLS 1.3 Encrypted 🔒 AES-256 at Rest 🛡 Zero Plaintext Token Storage ✅ Client Sandbox Isolation

Muscle OS takes personal data, biometric safety, and user privacy with extreme seriousness. This document outlines the multi-layered cryptographic safeguards protecting your workout logs, nutritional metrics, and authentication credentials.

1. In-Transit Encryption (Network Layer)

All network communications between your browser or mobile client and Muscle OS servers are secured via modern transport layer cryptography:

  • Mandatory HTTPS & TLS 1.3: Insecure HTTP connections are permanently prohibited and automatically upgraded to TLS 1.3.
  • HSTS (HTTP Strict Transport Security): Enforced with a 1-year max-age (31,536,000 seconds) to eliminate SSL-stripping vulnerabilities and man-in-the-middle exploits.
  • Edge-Terminated Modern Ciphers: Global edge endpoints (Cloudflare) enforce strong forward-secrecy cipher suites (ECDHE-ECDSA-AES128-GCM-SHA256, CHACHA20-POLY1305).

2. Client-Side Storage & Encryption

Because Muscle OS tools operate as high-performance offline-first Progressive Web Apps (PWAs), key workout logs and biometric calculations reside on your device:

Client-Side Cryptographic Helper (mos-crypto.js)

Sensitive user data—including health intake drafts, injury notes, and session tokens—is protected using client-side cryptographic obfuscation and salted hashing prior to persisting in browser localStorage. This prevents unauthorized reading by malicious browser extensions or inspection tools.

  • Same-Origin Sandboxing: Browser localStorage is isolated by origin (https://muscleos.coach) and cannot be accessed by external websites.
  • Zero Plaintext Passwords: Muscle OS uses Google OAuth 2.0 and cryptographically signed session tokens. We never collect, transmit, or store plaintext user passwords.

3. Cloud Infrastructure & Database Encryption

For cloud-synced athlete profiles and coaching databases:

  • Storage Encryption (AES-256): Supabase PostgreSQL databases and Cloudflare KV volumes are encrypted at rest using AES-256 block ciphers with automated key rotation.
  • Payment Card Isolation: Muscle OS servers never touch, receive, or store raw credit or debit card numbers. All payment transactions are handled exclusively by PCI-DSS Level 1 certified processors (Paymob, Vodafone Cash).
  • Automated Backups: Daily encrypted snapshots with point-in-time recovery and geographic redundancy.

4. Content Security Policy (CSP) & XSS Defense

Every page on Muscle OS serves strict Content Security Policy headers (Content-Security-Policy), X-Content-Type-Options: nosniff, and Referrer-Policy: strict-origin-when-cross-origin. These headers strictly restrict executable script domains to prevent cross-site scripting (XSS), data exfiltration, or malicious iframe injection.

5. Vulnerability Disclosure & Incident Response

We welcome responsible security research. If you discover a potential vulnerability in our tools or website, please notify us directly at security@muscleos.coach. We commit to acknowledging receipt within 48 hours and providing a remediation timeline.
