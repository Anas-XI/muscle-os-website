## What it is

Maxun is an open-source web scraping platform that lets you extract data from websites without coding. Useful for competitor research, fitness program analysis, supplement sourcing, and content aggregation.

## Key capabilities

- Visual scraper builder (point-and-click element selection)
- API-based extraction
- Schedule recurring scrapes
- Export to JSON/CSV
- Self-hostable (Docker)
- Handles authentication, pagination, dynamic content

## How to use in this project

- Scrape fitness competitor sites for program structures and pricing
- Extract supplement ingredient data from vendor sites
- Monitor健身 (fitness) forums for user pain points and feature requests
- Collect research papers from PubMed/Google Scholar for the vault

## Self-hosting

Maxun runs via Docker Compose. Deploy alongside Muscle OS on the same infrastructure for automated data pipelines into the vault.
