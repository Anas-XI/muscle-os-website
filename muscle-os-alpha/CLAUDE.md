# Muscle OS Alpha

Standalone desktop chat app for testing Muscle OS coaching. See `ARCHITECTURE.md` for full details.

**Stack:** React 19, TypeScript, Vite 6, Tailwind CSS 4, Zustand 5, Dexie.js, Electron (optional)

**Dev:** `npm run dev` → localhost:5173 (requires LM Studio on port 1234)
**Build:** `npm run build`
**Tests:** `npx vitest run` (94/94 passing)
