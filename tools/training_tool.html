📊 RPE / RIR Guide ▼
RPE (Rate of Perceived Exertion) and RIR (Reps In Reserve) help you auto-regulate intensity based on how you feel that day. Use the table below to find your target RPE for each rep range.
RPERIRFeelBest For
100Max effort — cannot do another repStrength testing, last set of main lift
91Hard — one more rep possible but very difficultTop working sets, heavy compounds
82Challenging — 2 reps left in tankMost working sets, hypertrophy
73Moderately hard — 3 reps leftBack-off sets, early working sets
5-64-5Moderate — bar speed slows slightlyWarm-up, ramp sets, first work sets
💡 Pro tip: Start your first working set at RPE 7. If it moves well, add weight next set. If it's a grind, stay or back off. Over 4 weeks, track your RPE to spot accumulating fatigue before it hurts performance.
